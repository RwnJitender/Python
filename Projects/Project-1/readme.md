# 📘 Python Type Conversion & User Input Demo

A beginner-friendly Python script that demonstrates:

- 🔄 Type Conversion (`int`, `float`, `str`, `bool`)
- ✅ Truthy & Falsy Values
- ⌨️ User Input Handling
- 🧠 Memory Address using `id()`
- 🏷️ Data Type Checking with `type()`

Perfect for Python beginners learning the basics of variables and data types.

---

# 🚀 Features

✔ Convert values between different data types  
✔ Understand how Python handles truthy & falsy values  
✔ Take input from the user  
✔ Display variable type dynamically  
✔ Show object memory address using `id()`
